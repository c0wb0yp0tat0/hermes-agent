# THE-NEXT-FAN — Plan (the next five-model fan-out's orchestration)

**Register:** plain, evidence-carrying. **Doctrine:** deployable (a dispatcher executes without elaboration); goals drive; nothing dismissed. **Amplification-law bound:** exponential, not linear.

## 1. THE FAN'S MISSIONS (five lanes, each with meter + amplification-lever)

**Lane A — C44-pilot sizing (seats: 2 models, split by grader).**
- Mission: run the C44-pilot at the 12h's actual params (temp>0, lowered gate, adjudicated labels); produce the measured sizing that replaces the refuted extrapolation.
- Meter: falsifiable — measured sizing vs. the refuted 12/15 fan-scale claim; grader = the external byte-direct audit + the certifying re-run within window; ungraded meters do not count.
- Amplification-lever: RECURSIVE-BREADTH — the pilot's measured sizing seeds the sub-mission split (two successors: the gate-sweep leg + the temp-sweep leg).

**Lane B — dependency-collapse parallel-arming (seats: 3 models).**
- Mission: identify every phase-gate that can arm in parallel per the evidence; convert sequence into concurrency wherever the evidence permits (no gate waits on a gate whose evidence is already present).
- Meter: count of gates parallel-armed per phase (60–240, 240–420, 420–600, 600–720); grader = the fold-receipt's witness line.
- Amplification-lever: DEPENDENCY-COLLAPSE — each parallel-armed gate feeds ≥2 successor arcs (fan-out-per-finding ≥2).

**Lane C — G5–G7 arcs' work-item definitions (seats: 2 models).**
- Mission: for each of G5, G6, G7, populate the three required fields — work-item → owner → deadline; no arc fires until all three are populated.
- Meter: field-completeness (3/3 per arc = fire-ready; grader = the fold-receipt's field-audit line).
- Amplification-lever: INSIGHT-COMPOUNDING — each completed arc-definition feeds multiple downstream arcs (the compounding-rate is a designed property: ≥2 successors per finding).

**Lane D — SOFT-pool sub-mission seeds (seats: 1 model + 1 sub-mission split).**
- Mission: take each SOFT-admitted item (NOT-TESTABLE-PARK, guard-fired skip, subset-win) and emit a sub-mission seed; each seed splits the breadth (doubles the breadth per split).
- Meter: seeds-emitted per SOFT item (target ≥1 seed per item; grader = the budget-ledger row + the independent witness).
- Amplification-lever: RECURSIVE-BREADTH — the sub-mission split is the amplification's engine (each split doubles the breadth; the fan-cap-9 is not a wall).

**Lane E — FLEET-scaling readiness (seats: 1 model).**
- Mission: measure each seat's concurrent-load capacity per phase and emit the scaling-readiness table (same seats doing MORE simultaneously, not just longer).
- Meter: concurrency-per-seat per phase vs. the phase's load; grader = the endurance-check receipt at 600–720.
- Amplification-lever: FLEET-SCALING — concurrency grows with phases' readiness; the capacity-per-phase's growth-ratio is a designed metric.

**Fan-topology:** caped at 9 (base + up to 8 copycat/swap legs). Composition this fan: 5 lanes × (base + split) = 9 max (Lane A splits once; Lane D splits once). No 12/15 refuted scale.

## 2. THE SEQUENCE

- **Phase 0–60 (hour-1):** the six-item shape executes (B4 probe, K-recency honest-negative, first-hour certifying re-run, instrument-inclusive sweep, upstream-mergeable pass, gates' frame). No re-planning; hour-1 executes.
- **Phase 60–240 (build + copycat fan-out):** Lanes A–E fire in parallel (dependency-collapse: no lane waits on another's evidence unless named); sub-mission splits arm at 120m.
- **Fold cadence:** ~90m. Fold-1 at ~90m (fast-cadence per-leg receipts present → slow cadence folds). Fold-2 at ~180m. Fold-3 at ~270m. Fold-4 (terminal) at ~600m. No fold without both cadences' receipts.
- **Phase 240–420 (audit + AoA + fold):** fold-3 lands; the joint-failure rows adjudicate; the SOFT pool's seeds enter the split queue.
- **Phase 420–600 (second fold cycle + adversarial pass):** fold-4 prep; the adversarial pass runs against the receipts; the C24d zero-delta check (measured delta = 0 across a fold → terminate; honest-negative accepted).
- **Phase 600–720 (terminal fold + endurance check + handoff):** terminal fold; endurance-clause verified; handoff receipt written.
- **Swap's next round:** the copycat/swap legs rotate at each fold (the swap's next round fires at fold boundaries, not mid-phase); a seat that ran Lane A in fold-1 may run Lane D in fold-2 if the evidence permits (dependency-collapse permits the re-arm).
- **Convergence's shape:** the receipts' dual-cadence integration produces the 24-fold artifact contract per fold (per-leg receipts + fold receipt + grader citation + independent-witness line); the convergence's diff is the authority.

## 3. THE AMPLIFICATION's ARITHMETIC (how the plan MEASURES the exponential)

- **Capacity-per-phase's growth-ratio target:** ≥2× per phase (60–240 → 240–420 → 420–600 → 600–720), measured as (legs-armed × folds-completed × seeds-emitted) / (legs-armed × folds-completed × seeds-emitted) prior phase. Linear re-scale is rejected by design.
- **Compounding-rate check:** fan-out-per-finding ≥2 at every fold; measured as (successor-arcs spawned) / (findings landed) at fold time. If <2 at any fold, the fold is non-amplifying and is flagged SOFT (budget cost 1) — never dismissed, always flagged.
- **Recursive-breadth check:** sub-mission splits count doubles per phase where evidence permits (splits_n+1 = 2 × splits_n); measured at each fold.
- **Fleet-scaling check:** concurrency-per-seat grows ≥1.5× per phase; measured at each fold.
- **Dependency-collapse check:** parallel-armed-gates / total-gates ≥0.5 by phase 240–420; measured at fold-2.
- **Terminal metric:** the 12h's total task-equivalents vs. the 8h's ~800; the ratio must be >8× (exponential, not linear) or the plan is non-amplifying and is flagged for the head's review.
- **Grader:** every meter cites its grader (external byte-direct audit / independent witness / certifying re-run within window); ungraded meters do not count; standing = graded + receipt on disk.

## 4. THE DISPATCHER's LINE (one-page execution-brief)

**Fires at t=0 (hour-1, no re-plan):** the six-item shape (B4 probe, K-recency honest-negative, first-hour certifying re-run, instrument-inclusive sweep, upstream-mergeable pass, gates' frame). **Fires at t=60 (phase 60–240):** Lanes A–E arm in parallel (dependency-collapse). Lane A (C44-pilot) runs at actual params; Lane B (parallel-arm) starts the gate scan; Lane C (G5–G7) begins field-population; Lane D (SOFT-pool) queues the seeds; Lane E (fleet-scaling) baselines concurrency.

**Fires at t=180 (fold-2):** dependency-collapse check (parallel-armed-gates/total-gates ≥0.5). Compounding-rate check (fan-out-per-finding ≥2). SOFT pool's seeds enter the split queue.

**Fires at t=270 (fold-3):** audit + AoA land; joint-failure rows adjudicate; G5–G7 field-completeness checked (3/3 = fire-ready).

**By whom:** the head fires the fan on go; the dispatcher enforces the three gates (evidence, verification, fold) per leg; the grader named per meter signs each receipt; the independent witness confirms before any canary pre-flag counts.

**Nothing dismissed:** every HARD exclusion recorded (receipt-less, mislabeled — no admission, no flag); every SOFT admission flagged + budget-ledger row; every zero-delta fold accepted as terminal, never a failure. The convergence's diff is the authority. The amplification's the law. Fire on the head's go.
