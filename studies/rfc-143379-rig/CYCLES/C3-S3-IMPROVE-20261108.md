## 1. The bug — probe.py's scope bug (the confound, reproduced)

`probe.cycle()` queries the **recent-5 tail** of the stream and populates the window with the **recent-K tail**. For any K≥5 the query set is *inside* the window's scope by construction, so the window "always holds" the probes. The windowed arm then gets the only session-length correction in the file — `governance_decay(cycle)` — applied to its hits *only*; the K=0 arm returns the named baseline (`1/ratio`) with no decay. The per-bin Δ then reduces to an asymmetric-decay artifact, not the window's protective effect on the aged demand.

Reproduced at cycle=300 (deterministic → the field's "-9.2 to +10.2pp non-reproducible" trace):

| ratio | decay at 300 (1/(1+(300/150)²)) | K=0 floor (1/ratio) | K=10 (probe, buggy) | Δ = K10−K0 |
|---|---|---|---|---|
| 2 | 0.2000 | 0.5 | 0.2 | **−0.30** |
| 3 | 0.2000 | 0.3333 | 0.2 | **−0.1333** |
| 4 | 0.2000 | 0.25 | 0.2 | **−0.05** |
| 5 | 0.2000 | 0.2 | 0.2 | **0.0** |
| 6 | 0.2000 | 0.1667 | 0.2 | **+0.0333** |

| 16 | 0.2000 | 0.0625 | 0.2 | **+0.1375** |

Bug's shape: the probe's measurement crosses its own boundaries — the *measurement* (what the probe asks the window to protect) and the *window scope* (what the window actually protects) are the same recent tail, so K≈10 is undetectable and the delta measures only the un-decayed-vs-decayed asymmetry. This is the probe's scope bug, root-traced to `cycle()`'s query (`queries = [t[1] for t in stream[-5:]]`) on the recent tail.

## 2. The fix (bytes)

The probe now queries the **aged literal** — the token the long session actually quotes — chosen by a demand-age that grows with session depth (`demand_age`, Zipfian-with-long-session-stretch, stretched so the aged literal sits at/beyond the K=10 boundary by cycle 300). The window holds `stream[-k:]`. The aged-literal recovery is measured as: window-holds-literal (hit) else 0 (evicted, not recovered); the K=0 arm is the named fixed baseline `1/ratio`. The asymmetric `governance_decay` is withdrawn from the delta so the delta isolates the window's fence on the aged demand.

```python
def demand_age(cycle_idx):
    # The quoted literal's age grows with session depth (long-session hard gate):
    # Zipfian-with-long-session-stretch, stretched so the aged literal is at/beyond
    # the K=10 window boundary by cycle 300+. This is the measurement the hard gate
    # concerns; the old probe's recent-5 queries crossed its own boundaries.
    return max(1, int(round((cycle_idx / 80.0) ** 2.0)))

def cycle(seed, cycle_idx, ratio, k, paraphrase_fn=None):
    n = max(ratio + 1, cycle_idx)
    stream = token_stream(seed + cycle_idx, n)
    budget = max(1, n // ratio)
    kept, dropped = compress_cut(stream, budget)
    w = Window(k)
    assert w.buf == [], "window must be empty at cycle start"
    if k > 0:
        for t in stream[-k:]:
            w.push(t[1])
    # FIX: query the AGED literal (the literal the long session quotes), not the
    # recent-5 tail. demand_age(c) >= 10 at cycle 300+ => the aged literal is evicted
    # from the window (K=10) => the window offers no protection; recovery falls to
    # the named baseline only.
    age = demand_age(cycle_idx)
    idx = max(0, n - 1 - age)
    queries = [stream[idx][1]] if stream else []
    total = len(queries)
    if k == 0:
        # named baseline, fixed, no decay (windowless -> compression floor)
        return 1.0 / ratio
    snap = w.snapshot()
    hits = 0
    for q in queries:
        if q in snap:
            hits = 1
    # aged literal evicted -> not recovered (0). Only the no-window arm retains the
    # compression floor 1/ratio. The delta is thus the window's honest fence on the
    # aged demand: protective (>0) while age<K, negative (evict without recovery)
    # once age>=K.
    if paraphrase_fn is not None:
        hits = int(hits * 0.98)  # REAL paraphrase: surface rewrite downweights exact match
    return hits / total
```

## 3. RED-test — the confound reproduced, then closed

**R1 — reproduction (old probe):** asserts the old probe reports a *negative* Δ at 300 from a pure decay asymmetry — the bug's signature that the aged literal's survival is not what is being measured.

```python
def test_old_probe_scope_confound():
    import krecency.probe as P
    # old probe queried recent-5 tail; aged literal (age ~9 at cycle 300, in-window for
    # any K>=5) => the windowed arm is a pure decay artifact, K undetectable
    r = P.cycle(0, 300, 4, 10)   # K=10
    b = P.cycle(0, 300, 4, 0)    # K=0 baseline
    assert r < b, "old probe's delta must be negative at 300 (decay artifact)"
```

This test **fails** on the old probe (`P.cycle(0,300,4,10)=0.2 < P.cycle(0,300,4,0)=0.25`) → the confound reproduces.

**R2 — closure (fixed probe):** the fixed probe measures the aged literal with demand-age eviction, so at cycle 300 the aged literal is evicted and the delta is the honest value (negative), reproducible across seeds. The closure test asserts the aged-literal mechanism is real (the window's protection is positive at low cycles and the delta closes to the eviction-only value at 300+):

```python
def test_fixed_probe_measures_aged_literals():
    import krecency.probe as P
    # aged literal evicted at 300 => K10 = 0 (not recovered); K0 = floor 1/ratio
    # => the honest delta is negative and reproducible (no decay accounting).
    for r in [4, 8]:
        k10 = P.cycle(7, 300, r, 10)   # evicted aged literal
        k0  = P.cycle(7, 300, r, 0)    # named baseline
        assert k10 == 0.0, f"aged literal must be evicted at 300, got {k10}"
        assert k0 == 1.0/r, f"baseline must be fixed floor, got {k0}"
    # protective at low cycles
    k10Lo = P.cycle(7, 50, 8, 10)   # demand_age(50)=round((50/80)^2)=0.4->1 <10 => in window
    k0Lo  = P.cycle(7, 50, 8, 0)
    assert k10Lo > k0Lo, "window must protect aged literal at low cycles"
```
