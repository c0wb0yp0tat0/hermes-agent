## The theme

The durable record survives the session's compression with its provenance intact, and the agent re-reads it rather than make the user repeat — the read restored, the store re-readable, the compaction governed, as one network.

## So what?

A Hermes user should be able to say "you're not listening" and have the agent re-read the durable record rather than make them repeat — and the record they anchor should survive the session's compression with its provenance intact. The doc-chain's network is the shape that gets there: the bounded read (Finn763's PR), the memory store's restore (#141876), the governed compaction (the provenance-origin + the K-recency, staged for their own home).

## The root-cause

The 5-whys, the legs the record holds:

1. **The symptom** — the 6,275 lines of compensation churn (the churn's defensible core is the
  ~30-line subset above; the total is the stack, not the cause). *Cause:* every session must re-derive what a single read gives, because the read's absent.
2. **Why absent** — the read action was removed (56ee8a5cc6), not deprecated; the substrate carries no `MemoryStore.read`.
3. **Why the churn persists** — the compensations (the doc-chain substrate, the dreaming prototype, the soft-compression path) each answer the read's symptom, none its root; they stack rather than close.
4. **Why the compaction loses fidelity** — at the lossy cut-point, two things die that the anchor's non-lossy boundary never had to carry: the exact recent text (paths, shas, args — the K-recency reason) and the identifier back to a unit's origin (the provenance reason).

The verified legs: 1–3 (the churn, the removal, the stack-not-close) — the record's. Leg 4's two sub-causes each map to one measured field failure — the exact-text loss to LOHA/ACD's recitation floor (2609.31430), the provenance loss to Source-Judged Compaction's 83% (2610.20927). **The unverified leg (flagged, not asserted):** *why the read crashes on the PR head specifically* — the record shows the collection error, not its parent bug; that's the dive-deep the owning PR must still do. **Now verified by execution (10-24/25):** the collection error was the stale base, not a read bug — jfugalde's run and Finn763's rebase of #116673 (head `ffc651bd11`, clean, mergeable) closed it; both on the record, reported here, not re-derived.

## The acceptance criteria

Proposed from the battery on disk; the team's to sign off the thresholds:

- [x] The read-action battery goes RED→GREEN at the restore (the verified flip: 23 failed → 35 passed) — the sandbox's run verified it end-to-end.
- [x] The stress battery's floors hold after the restore: 200/200 write-then-read, 800/800 concurrency survivors (0 corrupt), 100/100 re-read idempotence, 20/20 over-budget refusals — the runs on disk.
- [ ] The K-recency window's falsifier: it measurably improves exact-recitation at the 4×/8×/16× headline ratios (the +2.2/+1.1/+2.3pp held) — the gain's on the runs.
- [ ] The long-session hard gate — PASS/FAIL, not an open question. At 300+ agent cycles the K-recency window's exact-recitation must sit ≥ 0pp vs the K=0 baseline — never below — measured at the compression ratios production sessions actually run (4×–8×), evaluated across the whole run, not at the headline ratio alone. Any single measured point in the 300+ band below baseline at any ratio in 4×–8× fails the gate. This is the field's bar (3oltan-seo): a multi-hour production contour does not ship on a short-session extrapolation.
  - Status today: FAIL. The current data does not clear it — 300-cycle, K=10 landed 6.1% vs the 9.6% baseline (−3.5pp), below the line. The 150-cycle falsifier passing is necessary but not sufficient.
  - The honest caveat — the ruler's broken, the gate's not waived. The −3.5pp isn't the final word, and it isn't grounds to waive the gate. Across the runs the 300-cycle delta was non-reproducible (−9.2 to +10.2pp), root tracing to a scope bug in the probe itself — the measurement, not the window, was confounded. Under mock-forced paraphrase the window held stable at +1.1pp. So today's result is a broken ruler, not a reading: it can't certify the window safe, nor broken. Both the −3.5pp headline and the +1.1pp mock-stable are disqualified as certifying evidence until the probe's fixed. The gate stands — the Governance Decay reproduction (recency eviction → 100% violation, arXiv 2606.22528, DeepSeek-V4) is exactly the tail a soft gate lets through.
  - Measurement protocol: (1) fix the probe's scope bug first, no certifying run on the old probe; (2) sweep to and past 300 cycles to the field's longest contour, fixed K=10; (3) report per-cycle/per-bin Δ at every ratio in 4×–8× plus the headline ratios — the whole curve, not the endpoint; (4) baseline named and fixed; (5) paraphrase real, not mocked, for the certifying run (mock +1.1pp is a sanity check only); (6) judged on the worst case, not the mean — pass only if minimum Δ over all cycles ≥300 is ≥0pp at every 4×–8× ratio; one sub-zero point = FAIL.
- [x] Provenance survives the compression: a compacted unit carries a resolvable origin back to its archived original (the SJC 83% guard) — the governed-compaction leg, staged in its own home.
