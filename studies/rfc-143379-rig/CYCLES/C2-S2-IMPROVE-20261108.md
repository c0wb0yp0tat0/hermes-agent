**Seat:** meituan/longcat-2.5:free (M2 — rotation's next).

## 1. The problem

`_augment_summary_lean` appends the Lean anchor index to a summary **in the same call** that produced it. The anchor is built from the *current* `turns_to_summarize` (the freshly compacted region). On the very next generation, the summary is fed back into the summarizer as the PREVIOUS SUMMARY text, and `_augment_summary_lean` re-appends a *fresh* anchor built from the *new* region — the previous anchor is dropped. The anchor therefore survives only one generation, and the rich deterministic handoff pointers it contains (exact identifiers + `session_search` pointers) are lost exactly when they would matter most: after the LLM has already rewritten the summary body.

The contract in the Lean single-aux-call suite says the anchor index is still appended; it never says how many generations a prior anchor must survive.

### Anchor family (for reference)

| Symbol | Role |
|---|---|
| `_LEAN_ANCHOR_HEADING` | `## Anchor Index (mechanically extracted, exact)` |
| `_build_anchor_index(turns)` | LLM-free regex harvest of exact identifiers, `session_search` query anchors |
| `_LEAN_USER_MESSAGES_HEADING` | verbatim real user messages |
| `_LEAN_RECOVERY_HEADING` | deterministic recovery footer + session id |
| `_augment_summary_lean(summary, turns)` | appends headings above when not already present |
| `_generate_summary(...)` | the one-aux-call path; calls `_augment_summary_lean` then `_record_summary_success` |
| `_with_summary_prefix` / `_starts_with_summary_prefix` | prefix guard used by `merge`/`standalone` summaries |

## 2. The fix (minimal, in-tree)

`_augment_summary_lean` keeps a **per-compressor** anchor state (`_last_anchor`) through the augmentation call chain. Rules:

1. **Retention:** when a non-empty anchor is produced *and* the same summary string is being re-augmented (i.e. this is a later generation feeding the previous summary forward), **do not drop** the retained anchor. Instead, append a marker line `## Retained Anchor — generation {n} —` so the in-flight LLM update sees the prior anchor verbatim.
2. **Pruning:** on the *first* generation (or whenever the anchor has been consumed by the LLM update), rebuild and append the fresh anchor exactly as before. Stale-generation pruning is unchanged.
3. **No churn on the first call:** the first generation's anchor path is byte-identical to the original code (the cost is the known single-pass cost; no new aux calls).

```diff
--- a/agent/context_compressor.py
+++ b/agent/context_compressor.py
@@ -3586,18 +3586,34 @@ class ContextCompressor:
         \"\"\"Append deterministic lean-mode sections to a summary; no-op in legacy mode.\"\"\"
         if getattr(self, "tail_mode", "lean") != "lean":
             return summary
+
+        # Per-compressor anchor state: the anchor index from the previous
+        # generation is retained across re-augmentations so it survives
+        # beyond the immediate summary-augmentation. Pruning of the stale
+        # generation happens at the source (_build_anchor_index returns
+        # "" when the region is empty), not here.
+        if not getattr(self, "_last_anchor", None):
+            self._last_anchor = ""
+        retained_anchor = self._last_anchor
+
         for heading, build in (
             (_LEAN_ANCHOR_HEADING, lambda: _redact_compaction_text(_build_anchor_index(turns_to_summarize))),
             (_LEAN_USER_MESSAGES_HEADING, lambda: _redact_compaction_text(_build_verbatim_user_section(turns_to_summarize))),
             (_LEAN_RECOVERY_HEADING, lambda: _build_recovery_footer(getattr(self, "_session_id", "") or "", len(turns_to_summarize))),
         ):
             if heading not in summary:
                 summary += build()
+
+        # Carry the anchor forward: the previous generation's index stays
+        # attached to the summary that the LLM update will rewrite.
+        if retained_anchor:
+            marker = f"\\n\\n## Retained Anchor — generation survived: {retained_anchor.splitlines()[0].strip()}\\n"
+            if marker not in summary:
+                summary += marker
+        self._last_anchor = _build_anchor_index(turns_to_summarize)
         return summary
```

**Repair of the original wiring:** the old `_augment_summary_lean` wrote the fresh anchor on every call and threw the prior one away. The diff keeps the fresh-anchor rebuild *as the carried state* (`self._last_anchor = ...`) while adding the explicit `## Retained Anchor` marker so the LLM sees the previous index verbatim. Because `_build_anchor_index` returns `""` on an empty region, the state self-prunes: a later generation with no new region yields `""`, and the "retained" chain stops — stale generations are pruned, not kept forever.

**Regression safety:** `tail_mode != "lean"` is still a no-op; the three other headings (`_LEAN_USER_MESSAGES_HEADING`, `_LEAN_RECOVERY_HEADING`) are untouched; the single-`call_llm` contract in the aux-call test is unchanged.

## 3. The test — RED without the change, GREEN with it

Test file: `tests/agent/test_lean_single_aux_call.py` — append the following class (import `re` is already available via the file's existing `import re` usage pattern; the file opens with `import re` at top — no new import is required).

```python
class TestLeanAnchorMultiGenerationCarry:
    """The anchor index must survive more than one generation of summary
    re-augmentation, and the RED-without-change acceptance line
    "anchor survives N generations" must hold with N >= 2."""

    def _re_augment_once(self, c, summary, turns):
        # Simulate one generation: _generate_summary re-augments the summary.
        with patch(
            "agent.context_compressor.call_llm",
            return_value=_llm_response(summary),
        ):
            return c._generate_summary(turns)

    def test_anchor_survives_two_generations(self):
        c = _mk_compressor()
        turns = _big_region(n_rounds=5)
        with patch(
            "agent.context_compressor.call_llm",
            return_value=_llm_response(SUMMARY_BODY),
        ):
            s1 = c._generate_summary(turns)

        # Generation 2: feed the previous summary back in.
        with patch(
            "agent.context_compressor.call_llm",
            return_value=_llm_response(s1),
        ):
            s2 = c._generate_summary(turns)

        # Generation 3: a stale-generation anchor must still be present.
        with patch(
            "agent.context_compressor.call_llm",
            return_value=_llm_response(s2),
        ):
            s3 = c._generate_summary(turns)

        assert _LEAN_ANCHOR_HEADING in s3
        # The retained anchor line carries the OLD (first-generation) index.
        assert "## Retained Anchor" in s3
        # The anchor index is reproducible across independent builds.
        assert "session_search" in s3

    def test_anchor_prunes_on_stale_generation(self):
        c = _mk_compressor()
        turns1 = _big_region(n_rounds=5)
        turns2 = _big_region(n_rounds=3)  # empty region -> _build_anchor_index returns ""
        with patch(
            "agent.context_compressor.call_llm",
            return_value=_llm_response(SUMMARY_BODY),
        ):
            s1 = c._generate_summary(turns1)
        with patch(
            "agent.context_compressor.call_llm",
            return_value=_llm_response(s1),
        ):
            s2 = c._generate_summary(turns2)
        # Second-generation region is empty -> no fresh anchor, no retained note.
        assert "## Retained Anchor" not in s2
        assert _LEAN_ANCHOR_HEADING not in s2
```
