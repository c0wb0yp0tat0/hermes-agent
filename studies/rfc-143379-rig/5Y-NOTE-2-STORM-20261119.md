# 5Y-NOTE-2 STORM DOC — "we can go this direction" (the probe-first direction, field-methodologized), 2026-11-19

*Storm doc for 5Y-NOTE-2. The note asked: why can we go probe-first (the PersistGym two-arm)? The storm answers with the field's probe-design canon — and it adds two findings that upgrade the probe's design itself: an upper-bound arm that separates model error from substrate error, and an eviction-class paper that is the read-restore's falsifier in field dress.*

## The findings (mechanism per class, receipted)

**F1 — FIDELITY BEFORE STRUCTURE: THE DOC-CHAIN'S CORE WINS FIELD-VERIFIED (arXiv 2601.00821, "Fidelity Before Structure"):** controlled ablation — only the stored representation changes (verbatim chunks vs LLM-extracted typed artifacts), model/retriever/reranker/judge constant. **Verbatim chunks win by 15.9 points on LoCoMo (43.9 vs 28.0) and 22.0 points on LongMemEval-S (67.4 vs 45.4).** A semantic graph does NOT recover the gap; six confound controls reproduce it. "Accuracy tracks how much source text survives in the store." "Structured memory should augment verbatim text rather than replace it." Translation: the doc-chain's whole premise — the durable record held verbatim, provenance intact — is the field's measured winner over lossy extraction. The RFC's K-recency exact-recitation + provenance-origin classification are the same mechanism, now with the field's numbers behind them. The probe must include the verbatim-vs-extracted axis; the substrate is the verbatim arm's champion.

**F2 — MEMDELTA: THE ONE-FACTOR-AT-A-TIME LAW AND THE ARM-VOCABULARY (arXiv 2606.29914):** evaluation built on a single principle — vary one factor at a time, paired conditions, model/judge/questions/history fixed. The arm-set becomes a vocabulary: **S0 (question only — lower bound), S1 (full history — diagnostic CEILING: "removes retrieval as a bottleneck, allowing us to measure whether a model can use information when it is explicitly present"), S_rand (random chunks — controls for 'having text' vs 'relevant text'), the retrieval arms (S4/S4b — byte-identical except embedding), the scratchpad arm (S2), the extraction arm (S3).** Reset per question, fresh store, no leakage. **Cost is not secondary: "a strategy that wins by 2pp at 100× the ingest cost is a different artifact than one that wins at parity."** Translation: the probe's two arms get the field's exact names (the raw arm = S1-class control; the memory-off control under the same context budget = VibeMemBench's condition contract, F5). The cache-hit logging + cost-per-success (the master's M1 dollar line) is MemDelta's "cost is not secondary" — field-mandated, not optional.

**F3 — MEMPROBE: THE FOUR PARADIGMS (arXiv 2609.30558, EMNLP 2026):** cognitive-science framework: interference, misinformation, consolidation strength, reconsolidation window; encoding–perturbation–probing episode structure with filler/near-miss distractors; 56-episode diagnostic suite; behavioral profiles beyond aggregate accuracy ("systems with similar aggregate scores exhibit distinct behavioral profiles"). Translation: the probe can carry the non-observable-fact class AS a Misinformation/Interference paradigm with the field's episode structure — the probe is not ad-hoc; it has a published template to cite and follow.

**F4 — CONMEM: THE PROBE TRIPLET + THE INDEPENDENT PROBE AUDITOR (arXiv 2610.33432):** every candidate memory evaluated across **{relevant, irrelevant, risk}** probes; control vs treatment differ EXCLUSIVELY by memory access (identical configs, historical context withheld from both branches — "to isolate the direct causal impact of M"); and an **independent probe auditor verifies no leakage of candidate memories, gold labels, or benchmark artifacts before evaluation.** Translation: the probe's episodes need the triplet shape (the relevant probe = the 92.5-class test; the irrelevant = the "no harm when not needed" control; the risk = the over-retention/wrong-carry test), and the probe's episodes need an independent audit — the rig's AoA-on-a-different-base applying to the probe itself. The "not confirmed where unreadable" clause = zero-leakage discipline.

**F5 — THE RESTORE-COUNTERFACTUAL: THE READ-RESTORE'S FALSIFIER, FIELD-PUBLISHED (arXiv 2609.08279, "What Eviction Destroys"):** "when history exceeds a fixed token budget… budget–accuracy frontiers quantify the resulting loss in read-time context and reruns the same reader" — the restore-counterfactual audit: rerun the same reader with the evicted content restored, measure correctness change. Translation: this IS the read-restore's falsifier protocol, already published. The substrate's claim — restore lifts the truncated arm toward the full-context ceiling — can cite the counterfactual audit as its experimental home; the probe's oracle arm (F6) mechanizes it.

**F6 — T-BENCH'S ARMS = THE PROBE'S ARMS (tulv.ing/report-v1):** the field's episodic-memory diagnostic runs **raw (full context, control) · oracle (only the evidence turns — "an upper bound separating model error from architecture error") · naive RAG (policy-free baseline) · blind-summarization (LexRank, no query awareness) · retrieval.** Oracle at 0.985 vs raw 0.955 vs naive RAG 0.900 — the ordering shows what each arm isolates. Translation: the probe gains its strongest arm — **the ORACLE arm (evidence-only turns): it separates "the model cannot use the fact when shown" (architecture-independent model failure) from "the substrate failed to deliver the fact" (the read's failure) — the exact attribution the RFC's three-state spread needs.** The blind-summarization arm = the ungoverned-compaction baseline the substrate's governed compaction must beat.

## The refinement to the 5Y (what this changes)
- The direction is not just open — it is field-mapped. The probe becomes a standard-arms design: raw (S1-class) · oracle (upper-bound attribution) · truncated-uncompensated (the field's blind-summarization baseline) · substrate (the treatment) · cost + cache-hit logged on every arm, reset per episode, triplet probes, independent probe audit, one factor varied at a time.
- The prediction sharpens: the substrate arm should track the oracle arm, not just beat the truncated arm — the read-restore's whole claim is "the substrate delivers what the reader can use"; the oracle is its ceiling.
- The verbatim-vs-extracted finding (F1) is the RFC's external corroboration: fidelity is measured, not asserted — the probe can carry that axis explicitly.
- The restore-counterfactual (F5) is the read-restore's own falsifier, already published — the study can cite it as the protocol's canonical form.
