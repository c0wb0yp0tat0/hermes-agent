## 3. Unratified acceptance criteria — the ratification path

The RFC's criteria are proposed, not signed ("the team's to confirm"). Ratification path: the verdict vocabulary below, applied **to the field's own numbers**, not to our own batteries:

| Verdict | Meaning | The seam/azimuth |
|---|---|---|
| **COVERED** | The substrate's claim survives the field's ruler and the criterion is signed | PersistGym A vs B + Continual-ARC verify both recorded, no GAP |
| **PARTIALLY-COVERED** | the claim holds on one stamp but not the other; the seam is named | Arm A clear, Arm B not (or vice versa) |
| **GAP** | the field's door is closed (seed undisclosed / stream unreachable) and settling evidence is named | the verify run has no verdict; we record what blocks it |
| **UNKNOWN** | the probe ran but the measurement is not trusted | the broken-ruler class: the ruler itself is in question, settling evidence named |

The criterion is ratified only under COVERED; PARTIALLY-COVERED names the seam and stops public surfacing on that seam; GAP/UNKNOWN stop the claim and name the settling evidence. Every verdict names its settling evidence.

## 4. Two-way door on every move

- Run → abort: every probe can be aborted mid-run; the run log is preserved; the last good state is the record. No probe is committed by default.
- Public → private: nothing public ships without the user's word (the gate); if the user revokes, the record re-arms to the last private value.
- Adoption → no-adoption: the release-point intake (M3) and the window-calendar line (M2) are adoption probes; adoptative changes can be un-adopted without rework of the spine.
- Cost → no-cost: if a leg's billed cost exceeds the class cap, the leg stops and records COST-OVER, no re-plan without the user's word.
