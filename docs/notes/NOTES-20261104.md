On the merge head d1bdb458 (PR #139606), the module-level capability probe in tests/tools/test_write_gate.py reads the MODULE, not the entry-point function:

    _DOC_CHAIN_PRESENT = getattr(_memory_tool_mod, "DOC_TARGET_PREFIX", None) is not None

tools.memory_tool defines DOC_TARGET_PREFIX at module scope (lines 43-51), via a guarded import from tools.memory_tool_store:

    try:
        from tools.memory_tool_store import DOC_TARGET_PREFIX, doc_name, doc_target
    except ImportError:
        DOC_TARGET_PREFIX = None
        doc_name = None
        doc_target = None

The old probe (pre-fix, before 7c69692640) read getattr(memory_tool, "DOC_TARGET_PREFIX", None) where memory_tool is the entry-point FUNCTION (line 289). Python functions do not expose module-level names as attributes, and no setattr exposes DOC_TARGET_PREFIX on the memory_tool function (0 hits; universal search returns 4,320). The probe returned None on EVERY head, composed or standalone. The 10 doc-chain tests were unreachable on every head before the fix; their "skip reason" was a probe artifact, not a reason.

The fix (7c69692640, +11/-5, one file) changes the probe target from the function to the module. That is the entire behavioral change.

## 2. Method addendum (the new way we tested)

### 2.1 The shape

The method: run the same suite on two legs, the rig and GitHub's hosted runners, with the same pins, and treat divergence as data.

- Leg 1 (rig): local canonical runner, scripts/run_tests.sh. Receipts: 51✓/0✗/10 skipped (test_write_gate.py), 15✓/0✗ (test_spa_integration.py + test_dream_cycle.py), base full tree 50001✓/69✗/850 skipped.
- Leg 2 (hosted): GitHub Actions rig-hosted-verify, same pins. Run 41729692136 completed success on the write-gate canonical suite. Run 41758172296 in flight (-rs read-back).

When the two legs agree, the receipt is strong. When they diverge, the divergence is itself a finding: it names an environment-bound failure class (container mirroring, import-gaps) rather than a code defect. This is the receipts-first contract: every number carries its runner, its pins, and its environment.
